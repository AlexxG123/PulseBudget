# Pulse Budget

A desktop personal finance tracker built with Python and CustomTkinter.  
This application helps users register income and expenses by category, showing monthly summaries with visual percentage bars.

## Requirements
- Python 3.10 or higher
- CustomTkinter library

## How to run
1. Install the dependency: `pip install customtkinter`
2. Run the application: `python main.py`
